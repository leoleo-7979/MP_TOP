[검정 바탕 + 흰색 MP + 보라색 별] 아이콘 세트
PC(브라우저 탭), 모바일(iOS/안드로이드 홈 화면), 태블릿(아이패드)까지 모두 쓸 수 있게 여러 크기로 만들었습니다.

■ 들어있는 파일
- favicon.ico, favicon-16x16.png, favicon-32x32.png, favicon-48x48.png
  → PC/노트북 브라우저 탭 아이콘, 즐겨찾기 아이콘
- apple-touch-icon.png (180x180), apple-touch-icon-152x152.png, apple-touch-icon-167x167.png, apple-touch-icon-120x120.png
  → 아이폰/아이패드에서 "홈 화면에 추가"할 때 쓰는 아이콘
- icon-192.png, icon-512.png, icon-maskable-192.png, icon-maskable-512.png
  → 안드로이드 홈 화면 추가, PWA(웹앱 설치) 아이콘
- mstile-150x150.png
  → 윈도우 시작 화면/작업줄에 고정할 때 쓰는 아이콘
- manifest.json
  → "웹앱처럼 설치" 기능을 위한 설정 파일 (이름, 배경색, 아이콘 목록)

■ 적용 방법
1. 이 폴더의 모든 파일(13개 이미지 + manifest.json)을, 사이트의 웹페이지(index.html 등 9개 html 파일)와
   "같은 폴더"에 그대로 올려주세요. (Netlify라면 배포하는 폴더 안에 같이 넣으면 됩니다.)

2. 9개 html 파일 전부의 <head> 안에, 기존에 있던
     <link rel="icon" type="image/png" href="data:image/png;base64,...">
   줄을 지우고, 아래 내용을 통째로 붙여넣어 주세요.

   <link rel="icon" type="image/x-icon" href="favicon.ico">
   <link rel="icon" type="image/png" sizes="16x16" href="favicon-16x16.png">
   <link rel="icon" type="image/png" sizes="32x32" href="favicon-32x32.png">
   <link rel="icon" type="image/png" sizes="48x48" href="favicon-48x48.png">
   <link rel="apple-touch-icon" href="apple-touch-icon.png">
   <link rel="apple-touch-icon" sizes="120x120" href="apple-touch-icon-120x120.png">
   <link rel="apple-touch-icon" sizes="152x152" href="apple-touch-icon-152x152.png">
   <link rel="apple-touch-icon" sizes="167x167" href="apple-touch-icon-167x167.png">
   <link rel="manifest" href="manifest.json">
   <meta name="theme-color" content="#0a080e">
   <meta name="apple-mobile-web-app-capable" content="yes">
   <meta name="apple-mobile-web-app-status-bar-style" content="black-translucent">
   <meta name="msapplication-TileImage" content="mstile-150x150.png">
   <meta name="msapplication-TileColor" content="#0a080e">

3. 저장하고 다시 배포하면 끝입니다. 적용 후 확인하는 방법:
   - PC: 브라우저 탭에 아이콘이 바뀌어 보이는지 확인 (강력 새로고침 Ctrl+Shift+R 또는 Cmd+Shift+R 필요할 수 있음)
   - 아이폰/아이패드: 사파리로 사이트 열기 → 공유 버튼 → "홈 화면에 추가" → 아이콘 미리보기 확인
   - 안드로이드: 크롬으로 사이트 열기 → 메뉴(⋮) → "홈 화면에 추가" 또는 "앱 설치" → 아이콘 확인

※ 저에게 이 9개 html 파일을 다시 반영해달라고 하시면, 이 태그들을 직접 파일에 넣어서 바로 드릴 수도 있어요.
